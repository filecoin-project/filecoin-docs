# Upload to Filecoin

This guide walks you through the fastest ways to store data on Filecoin. Options are ordered from simplest to most advanced.

## Quick path: Filecoin Onchain Cloud

[Filecoin Onchain Cloud (FOC)](../../build/advanced/filecoin-onchain-cloud.md) is the recommended starting point for most users. FOC provides a managed, on-chain storage experience with minimal setup.

{% hint style="success" %}
**Best for**: developers who want programmatic, on-chain storage with minimal infrastructure.
{% endhint %}

*Content coming soon — setup steps, CLI quickstart, and first upload walkthrough.*

## Subsidized storage: Filecoin Plus

[Filecoin Plus](filecoin-plus.md) offers verified deals with subsidized storage costs. Verified clients receive DataCap, which can be spent with storage providers to store data at no cost beyond gas fees.

{% hint style="success" %}
**Best for**: large dataset storage where cost efficiency is a priority.
{% endhint %}

*Content coming soon — how to apply for DataCap, allocator flow, and making your first verified deal.*

## Managed ingestion: storage onramps

[Storage onramps](storage-onramps.md) are third-party services that abstract Filecoin deal-making into simple API calls or drag-and-drop UIs.

{% hint style="info" %}
**Best for**: teams who prefer a managed service and don't need direct on-chain control.
{% endhint %}

*Content coming soon — comparison table of onramp providers, quickstart links.*

## Advanced: direct deal-making

For full control over the storage workflow, you can interact directly with storage providers using tools like [Boost](https://boost.filecoin.io/) or the [Lotus client](../../storage-providers/nodes/implementations/lotus.md).

{% hint style="info" %}
**Best for**: storage providers, large-scale data onboarders, and users with custom deal requirements.
{% endhint %}
