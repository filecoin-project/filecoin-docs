# How storage works

New to Filecoin storage? Start with the [Upload to Filecoin](./upload-to-filecoin.md) guide for the fastest path to storing data on the network.

This section covers the primary methods for storing data on Filecoin — from the simplified [Upload to Filecoin](./upload-to-filecoin.md) guide, to the [Filecoin Plus](./filecoin-plus.md) program for subsidized storage, to [various storage onramps](./storage-onramps.md) for managed ingestion. It also explains the features and advantages of using [Filecoin and IPFS](./filecoin-and-ipfs.md).
