# Tools

**Tools for building on Filecoin.** This page lists tools from Filecoin project repos.

## Filecoin Cloud tools

* **Filecoin SDK:** upload and manage data from your app. See [Filecoin SDK](../store-data/tools/filecoin-sdk.md).
* **Filecoin CLI:** store and retrieve data from the command line. See [Filecoin CLI](../store-data/tools/filecoin-cli.md).
* **Filecoin Pin:** store IPFS content on Filecoin Cloud. See [Filecoin Pin](../store-data/tools/filecoin-pin.md).

## Wallets

* **Filsnap:** adds Filecoin to MetaMask. [filecoin-project/filsnap](https://github.com/filecoin-project/filsnap)

## Built-in actors

* **Built-in actors:** [filecoin-project/builtin-actors](https://github.com/filecoin-project/builtin-actors)
* **FVM example actors:** [filecoin-project/fvm-example-actors](https://github.com/filecoin-project/fvm-example-actors)
