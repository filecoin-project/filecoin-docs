# Specifications

**The Filecoin specification describes how the network works:** the rules for taking part, the format of messages, and how data is stored and proven. It changes as the network grows.

* Read it at [spec.filecoin.io](https://spec.filecoin.io/).
* Suggest changes on [GitHub](https://github.com/filecoin-project/specs).
* Network changes are proposed as FIPs: [filecoin-project/FIPs](https://github.com/filecoin-project/FIPs).
