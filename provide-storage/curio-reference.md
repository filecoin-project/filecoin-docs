# Curio reference

**Curio has its own docs: [docs.curiostorage.org](https://docs.curiostorage.org/).** Use them for full settings and every command. The pages in this section cover the main paths.

## Set up

* [Curio-PDP](https://docs.curiostorage.org/getting-started/curio-pdp): the Docker build for warm storage.
* [Installation](https://docs.curiostorage.org/installation): packages and building from source.
* [Setup](https://docs.curiostorage.org/setup): new miners and moving from lotus-miner.
* [Curio service](https://docs.curiostorage.org/curio-service): running Curio with systemd.
* [Storage configuration](https://docs.curiostorage.org/storage-configuration): attaching disks.

## Settings

* [Configuration](https://docs.curiostorage.org/configuration): layers and every setting.
* [Alert Manager](https://docs.curiostorage.org/configuration/alert-manager): alerts to PagerDuty, Prometheus or Slack.

## Storage market

* [Storage market](https://docs.curiostorage.org/curio-market/storage-market): taking client deals.
* [Migrating from Boost](https://docs.curiostorage.org/curio-market/migrating-from-boost): moving deals into Curio.

## Run and fix

* [Curio GUI](https://docs.curiostorage.org/curio-gui): the dashboard.
* [YugabyteDB backup](https://docs.curiostorage.org/administration/yugabyte-backup): backing up the database.
* [Troubleshooting](https://docs.curiostorage.org/troubleshooting): common errors and debug info.
* [sptool](https://docs.curiostorage.org/curio-cli/sptool): miner commands, such as withdraw and proving.

## Get help
