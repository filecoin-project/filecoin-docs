# The FIL token

**FIL is the native cryptocurrency of the Filecoin network. Users pay storage providers in FIL, the network rewards providers in FIL, and every message sent to the chain pays gas in FIL.**

To get FIL, see [Get FIL](get-fil.md).

## Uses

### Network payments

A user who stores data pays the storage provider in FIL, in advance, for the period the data will be stored. Providers set their own terms, so other payment options, such as fiat, can also be available.

### Blockchain rewards

The network pays FIL to storage providers that add blocks to the chain. A provider receives the consensus share of the [block reward](../economics/block-rewards.md) for each block it produces, and also earns the fees for the messages it includes.

### Gas

Every message sent to the chain, including smart contract calls on the FVM, pays gas in FIL. See [Gas](../fvm/gas.md).

### Collateral

Storage providers lock FIL as collateral when they commit storage. Collateral that a provider doesn't keep its promises on can be burned. See [Slashing](../economics/slashing.md).

### Governance

FIL holders are encouraged to take part in the [Filecoin governance process](https://fil.org/governance): proposing, discussing, designing and contributing to network changes alongside implementers, core developers, storage providers and other ecosystem partners.

## Supply

The maximum supply of FIL is 2 billion. Of that, 1.1 billion is released to storage providers as block rewards (330 million as simple minting and up to 770 million as baseline minting), as described in [Block rewards](../economics/block-rewards.md).

## Denominations

The smallest unit is the attoFIL, so one FIL is 10<sup>18</sup> attoFIL. Some actions on the network cost much less than a whole FIL, so you will see these smaller units across the ecosystem:

| Name | Units per FIL |
| --- | --- |
| FIL | 1 |
| milliFIL | 1,000 |
| microFIL | 1,000,000 |
| nanoFIL | 1,000,000,000 |
| picoFIL | 1,000,000,000,000 |
| femtoFIL | 1,000,000,000,000,000 |
| attoFIL | 1,000,000,000,000,000,000 |

Testnets use test FIL, written `tFIL`. It has no value. See [Get FIL](get-fil.md#test-fil).
