# Networks

**Filecoin has one production network and one public testnet, plus a private network you can run on your own machine. Use Mainnet for real FIL and storage, Calibration for testing, and a local testnet for fast, offline development.**

| Network | Use it for | Chain ID |
| --- | --- | --- |
| [Mainnet](mainnet.md) | Production, with real FIL and real storage | `314` |
| [Calibration](calibration.md) | Testing against a network that mirrors Mainnet, with free test FIL (`tFIL`) | `314159` |
| [Local testnet](local-testnet.md) | Private development on your own machine, with tiny sectors | `31415926` |

Networks that are no longer running are listed on [Legacy networks](legacy-networks.md).
