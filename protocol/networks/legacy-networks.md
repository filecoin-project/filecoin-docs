# Legacy networks

**These networks are retired. Don't use them. For testing, use [Calibration](calibration.md) or a [local testnet](local-testnet.md).**

| Network | What it was for | Retired |
| --- | --- | --- |
| Nerpanet | Application developers testing basic functionality with tiny sector sizes before moving to Calibration | 2021-08-16 |
| Wallaby | Internal Filecoin developers testing new features before Hyperspace and Mainnet. Reset every week | 2023-02-07 |
| Spacenet | The Interplanetary Consensus (IPC) project | 2023-09-11 |
