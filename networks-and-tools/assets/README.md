## USDFC

USDFC is a FIL-backed stablecoin issued by [Secured Finance](https://docs.secured.finance/usdfc-stablecoin/overview). Filecoin Onchain Cloud uses USDFC for storage payments.

| Network | USDFC token contract |
| --- | --- |
| Filecoin mainnet | `0x80B98d3aa09ffff255c3ba4A241111Ff1262F045` |
| Calibration testnet | `0xb3042734b608a1B16e9e86B374A3f3e389B4cDf0` |

See [the official contract addresses](https://docs.secured.finance/usdfc-stablecoin/deployed-contracts) and [how to get test USDFC on Calibration](../../build/developing-contracts/get-test-tokens.md#get-test-usdfc).
