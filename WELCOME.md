# Welcome to Filecoin Docs

**Filecoin is a decentralized storage network where independent storage providers store data and prove that they still hold it.** These docs cover storing data, connecting AI agents, providing storage, and building on the Filecoin protocol.

New to Filecoin? Read [What is Filecoin](getting-started/what-is-filecoin/README.md), or go straight to the [Quickstart](getting-started/quickstart.md).
