# Storage onramps

**Storage onramps are services that store data on Filecoin for you behind a familiar interface, such as an S3-compatible API or a web app.** Fil One, Akave, Lighthouse and CID Gravity are some of them, each with its own docs and billing.

## When to use a storage onramp

Pick a storage onramp if you want:

* A familiar interface, such as an S3-compatible API.
* Simple billing, without managing tokens or deposits.
* Filecoin-backed storage without running anything yourself.

If you want to control providers, copies and payments yourself, use [Filecoin Cloud](../README.md) directly.

## Fil One

Fil One is object storage that works like Amazon S3, backed by Filecoin. Point any S3 tool or SDK at its endpoint and store data as you do today. Pricing is a flat rate per terabyte, with no fees for downloading your data.

Best for teams that want to switch from S3 without changing their code.

See the [Fil One docs](https://docs.fil.one/) for the endpoint, SDKs and API reference.

## Akave

Akave provides decentralized object storage and data lakes backed by Filecoin, with built-in encryption.

See the [Akave docs](https://docs.akave.ai/).

## Lighthouse

[Lighthouse](https://lighthouse.storage/) offers permanent, decentralized storage powered by Filecoin.

## CID Gravity

[CID Gravity](https://www.cidgravity.com/) is a web app for uploading files to Filecoin and IPFS.
