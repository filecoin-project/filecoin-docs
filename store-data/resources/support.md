# Support

**If something isn't working, check the status page and the troubleshooting guide first.** If you're still stuck, open an issue on GitHub. For business questions, talk to sales. You can also ask the community.

## Check first

1. [Filecoin Cloud status page](https://status.filecoin.cloud): is there an outage or maintenance?
2. [Errors and troubleshooting](errors-and-troubleshooting.md): causes and fixes for common errors.
3. [FAQ](faq.md): short answers to common questions.

## Report a bug

Open an issue in the repository for the tool you're using:

| Tool | Repository |
| --- | --- |
| Filecoin SDK | [FilOzone/synapse-sdk](https://github.com/FilOzone/synapse-sdk/issues) |
| Filecoin CLI and agent plugin | [filecoin-project/agents](https://github.com/filecoin-project/agents/issues) |
| Filecoin Pin | [filecoin-project/filecoin-pin](https://github.com/filecoin-project/filecoin-pin/issues) |
| These docs | [filecoin-project/filecoin-docs](https://github.com/filecoin-project/filecoin-docs/issues) |

Include what you ran, the network (mainnet or Calibration), and the full error.

## Talk to sales

For enterprise storage, large datasets or storage platforms, [talk to sales](https://filecoin.cloud).

## Report a security issue

Don't report security issues in public channels. Contact the team privately at the security address for the affected project.

## Ask the community

Ask questions and get help from other builders and the team in the [Filecoin community channels](https://github.com/filecoin-project/filecoin-pin?tab=readme-ov-file#community-and-support).
